# 第 1 部分 基础篇：概念与规则操作

在动手写规则之前，先弄清 iptables 到底是什么、报文在内核里经过哪些关卡、规则如何存放，再学会对规则做「增删改查」。这三章是后面所有实验的基础。

本部分包含：

* [第 1 章 iptables 概念](01-concepts.md)：防火墙分类、netfilter 与 iptables 的关系、五条链、四张表、表链关系与优先级、规则与处理动作。
* [第 2 章 规则查询](02-list-rules.md)：`-t` / `-L` / `-v` / `-n` / `--line-numbers` / `-x`，`-v` 输出字段与计数器。
* [第 3 章 规则管理：增删改与保存](03-manage-rules.md)：`-A` / `-I` / `-D` / `-R` / `-P` / `-F`，规则顺序的影响，`-R` 的坑，以及规则持久化。

读完本部分，你应该能独立查看任意表、任意链的规则，并按预期顺序添加或删除规则。
